01

Select one page

Choose a PDF containing exactly one page. Encrypted, password-protected, malformed and multi-page files are rejected.

02

Impose four copies

The page is embedded once and drawn four times in a two-by-two arrangement. Vector content, text and images remain embedded as PDF content.

03

Download locally

The completed PDF is generated in browser memory and downloaded directly. No source or output document is transmitted.

Page-size calculation

The output page keeps the source orientation and uses the next size in the ISO A-series progression. Each dimension is multiplied by the square root of two. Each source copy is scaled by the reciprocal of the square root of two.

output width = source width × √2    output height = source height × √2 copy scale = 1 ÷ √2 = 0.7071067812

Examples

  • A5 becomes A4 with four reduced A5 copies.
  • A4 becomes A3 with four reduced A4 copies.
  • A3 becomes A2 with four reduced A3 copies.
  • Landscape source pages produce landscape output pages.
  • Non-standard page dimensions are enlarged proportionally.

Local-only document processing

Selected files are read by JavaScript in this browser tab. PDF parsing, page embedding, output construction and download creation all occur on this device.

No persistent history

The application does not retain conversion history, filenames, file sizes, completion times, source PDFs or generated PDFs in persistent browser storage.

Third-party library

The PDF processing library is loaded from a public CDN. The library code is downloaded by the browser, but your selected PDF is not sent to that CDN. Once loaded, conversion is performed locally.

Memory lifecycle

PDF bytes remain in browser memory until the document is cleared, replaced, or the page is closed. Generated object URLs are revoked when they are no longer required.
